# Prototipo de Juego Temático Vikingos

![Badges](https://img.shields.io/badge/viking-themed-brightgreen.svg)

## Descripción
Este es un prototipo de un juego basado en la temática vikinga que utiliza comandos de voz en español mediante el reconocimiento de voz de Google. El juego está desarrollado en Java y es solo de frontend, sin backend.

## Características
- Navegación por pestañas
- Ventanas emergentes
- Interacción mediante comandos de voz

## Tecnologías
- XML
- Google Speech Recognition

## Arquitectura
El juego está diseñado para ser una aplicación de frontend que utiliza el reconocimiento de voz para permitir a los jugadores interactuar con el mismo.

## Instalación
1. Clona el repositorio: `git clone https://github.com/KevinFlow-ai/Kingdom_King.git`
2. Navega a la carpeta del proyecto.
3. Ejecuta el archivo `Main.java` para iniciar el juego.

## Uso
Al iniciar el juego, puedes navegar usando las pestañas y utilizar los comandos de voz para interactuar con la interfaz.

## Comandos de Voz
- "Iniciar juego" para comenzar una nueva partida.
- "Ayuda" para obtener más información sobre cómo jugar.
- "Cerrar" para salir del juego.
